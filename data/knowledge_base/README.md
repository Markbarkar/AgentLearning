# 知识库文档目录

此目录用于存放用于构建知识库的文档。

## 支持的文件格式

- PDF (.pdf)
- 文本文件 (.txt)
- Word 文档 (.docx, .doc)
- Markdown (.md)

## 使用方法

1. 将法律文书、案例文档等放入此目录
2. 运行构建脚本：
   ```bash
   python build_knowledge_base.py
   ```
3. 启动 API 服务即可使用 RAG 功能

## 目录结构建议

```
knowledge_base/
├── 合同纠纷/
│   ├── 案例1.pdf
│   └── 案例2.pdf
├── 劳动争议/
│   ├── 案例1.pdf
│   └── 案例2.pdf
└── 其他案件/
    └── ...
```

## 注意事项

- 文档会被自动分块处理
- 支持递归处理子目录
- 建议文档内容清晰、结构化
- PDF 文件会使用 Qwen2.5-VL 进行 OCR 识别
